# Sample Test Data

This directory contains verified sample test images for evaluation and automated validation:

- `sample_images/frontal_neutral.jpg`: High-resolution, balanced-lighting frontal portrait with neutral expression and near-zero head pose tilt. Ideal for baseline facial symmetry analysis.
- `sample_images/turned_pose.jpg`: High-resolution portrait with an intentional head turn and tilt, ideal for testing head-pose estimation (`solvePnP`) and non-frontal suitability gating.
